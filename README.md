
<h1 align="center">🧠 Concise — AI-Powered Product Review Summarizer</h1>

<p align="center">
  <strong>Concise</strong> is a web-based NLP application that helps online buyers make smarter purchase decisions by automatically analyzing and summarizing product reviews.
</p>

<p align="center">
  Given a product link, the system fetches all reviews, performs sentiment analysis, extracts keywords, and generates concise <b>pros and cons</b> along with an <b>overall summary score</b>.
</p>

---

<h2>🚀 Key Features</h2>

<ul>
  <li>Automatic review fetching from product pages</li>
  <li>Per-review sentiment analysis (positive / negative / neutral)</li>
  <li>Keyword extraction to highlight common themes</li>
  <li>Generates concise <b>Pros</b> & <b>Cons</b> summary</li>
  <li>Provides an overall summary score for quick decision-making</li>
</ul>

---

<h2>🧩 Tech Stack</h2>

- **Frontend:** HTML, CSS, JavaScript (or React.js)  
- **Backend:** Python (Flask / FastAPI)  
- **Libraries:** NLTK, TextBlob, BeautifulSoup, Hugging Face Transformers, KeyBERT  
- **Database (optional):** SQLite / PostgreSQL  

---

<h2>⚙️ How It Works</h2>

1. User enters a **product link** (e.g., Amazon/Flipkart).  
2. Backend **fetches and preprocesses** all product reviews.  
3. NLP model performs **sentiment analysis** and **keyword extraction**.  
4. A **summary generator** produces Pros & Cons.  
5. The system calculates an **overall sentiment score**.  
6. Output is displayed clearly in the web interface.
